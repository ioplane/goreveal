## Navigation Rules

- Identify whether the task belongs to `core`, `schema`, `engine`, `deobfuscation`, `cli`, `storage`, `api`, `plugins`, `bench`, or `corpus`.
- Refuse to mix plugin-specific or storage-specific behavior into `core`.
- Prefer the smallest module boundary that can own the change.
- When in doubt, update docs before inventing structure in code.
- Treat current Sprint 11 package/type metadata and source-tree fields as active contract, not temporary output noise.
  This currently includes `external_packages`, package `module_local`/`has_source_evidence`, and type `import_path`/`source_file_count`/`module_local`/`user_meaningful`.
- Treat current Sprint 12 runtime fields as bounded contract slices, not permission for a broad runtime refactor.
  This currently includes raw `.typelink` evidence, `.itablink` evidence, the `firstmoduledata`/`.go.module` bridge, the `moduledata_typelink_*` / `moduledata_itablink_*` slice-header cross-checks, the bounded `moduledata_*range*` memory block fields, the `moduledata_rodata_*` / `moduledata_text_*` range fields, the fixture-local typelink semantic bridge, and the bounded `moduledata_pcheader_*` / `moduledata_funcnametab_*` / `moduledata_cutab_*` / `moduledata_filetab_*` / `moduledata_pctab_*` / `moduledata_pclntable_*` bridges.
- Treat bounded Sprint 12 UX projections as valid follow-up work when they only expose already-known truth.
  This currently includes function `package` / `import_path` / `module_local` / `source_file` / `source_line` / `autogenerated`, direct `inspect runtime`, string-candidate absolute `addr` projected from known region bases plus offsets, thin export-layer projection of the same canonical function/type/string metadata into `IDA` / `Ghidra` payloads, and adapter-side preference for canonical string `address` over raw `offset`.
- Treat the stripped ELF checkpoint as part of the active contract.
  This currently includes bounded `.go.module` fallback for `firstmoduledata_addr`, explicit `firstmoduledata_from_go_module_fallback` exposure in `analysis.runtime`, bounded function metadata for `package` / `import_path` / `module_local` / `source_file` / `source_line` / `autogenerated`, direct `inspect runtime` exposure for the bounded `analysis.runtime` contract, preserving only the `main` package as module-local through `build_info.path` when source-tree evidence is absent, exposing `has_source_evidence: false` when package metadata is not backed by real source files, allowing the same bounded `main` fallback for type metadata when a truthful type surface exists, returning `[]` rather than JSON `null` when stripped fixtures have no truthful type surface, and allowing a bounded `source-tree` fallback with empty file lists for module-local and external packages when truthful file evidence is absent while marking those nodes with `has_file_evidence: false`.

## Deliverable

Before implementation, be able to state:
- which module owns the change
- which docs govern it
- which tests or evidence must change with it
